## ✨ Features

- **Adaptive design** — three dedicated layouts for 360px (mobile), 768px (tablet) and 1168px (desktop)
- **Product cards** with hover effects
- **Modal window** with a contact form for customer inquiries
- **Mobile menu** for easy navigation on small screens
- **Anchor links** with smooth scrolling between sections

## 🛠 Tech stack

HTML5 · CSS3 · JavaScript

## 🚀 Run locally

git clone https://github.com/yanap1312/simply-chocolate.git
cd simply-chocolate

Then open `index.html` in your browser.
